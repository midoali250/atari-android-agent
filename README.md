# Atari Android Agent

هيكل مبدئي لمشروع تطبيق أندرويد لألعاب Atari، تمهيدًا لاختيار أول لعبة والبدء في التنفيذ.

> **الحالة الحالية:** تهيئة المستودع فقط. لا يوجد بعد تطبيق قابل للبناء، أو محرك محاكاة، أو ملفات ألعاب مضمّنة.

## هيكل المشروع

```text
atari-android-agent/
├── android/          # تطبيق الأندرويد وواجهة الاستخدام
│   └── README.md
├── core/             # منطق المحاكاة المستقل عن واجهة أندرويد
│   └── README.md
├── roms/             # ملفات الألعاب المصرّح باستخدامها
│   ├── .gitkeep
│   └── README.md
├── .gitignore
└── README.md
```

## مسؤوليات المجلدات

| المجلد | الغرض |
| --- | --- |
| [`android/`](android/) | شاشة التطبيق، التحكم باللمس، الصوت، العرض، ودورة حياة التطبيق. |
| [`core/`](core/) | منطق المحاكاة ومعالجة حالة اللعبة، مع إمكانية اختباره بشكل مستقل عن واجهة أندرويد. |
| [`roms/`](roms/) | ملفات الألعاب المستخدمة في الاختبار والتشغيل، وفق حقوق الاستخدام والتوزيع المناسبة. |

## مراحل العمل

- [x] إنشاء المجلدات الأساسية والتوثيق المبدئي.
- [ ] اختيار أول لعبة ونظام Atari المستهدف.
- [ ] تحديد تقنيات التطبيق ونهج المحاكاة.
- [ ] إنشاء تطبيق الأندرويد وربطه بالمحرك.
- [ ] اختبار العرض والصوت والتحكم، ثم تحسين الأداء.

## ملفات الألعاب والأمان

- لا يتضمن المستودع أي ملفات ROM حاليًا. استخدم فقط ألعابًا تملك حقوق استخدامها، وأضف إلى المستودع ملفات تملك تصريحًا بتوزيعها.
- لا تضع كلمات المرور أو رموز الوصول أو مفاتيح التوقيع داخل المستودع. إعدادات البيئة المحلية وملفات التوقيع مستثناة عبر `.gitignore`.

## الخطوة التالية

اختيار اللعبة الأولى، ثم تحديد متطلبات المحاكاة والتحكم المناسبة لها قبل بدء التنفيذ.
