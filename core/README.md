# Emulation core

مساحة منطق المحاكاة المستقل عن واجهة أندرويد.

## النطاق المخطط

- تنفيذ حالة النظام المستهدف وتحميل بيانات اللعبة.
- توليد الإطارات والصوت واستقبال مدخلات التحكم.
- واجهة واضحة بين المحرك وتطبيق الأندرويد.
- اختبارات للمحرك يمكن تشغيلها دون واجهة رسومية.

## الحالة الحالية

لا توجد شيفرة محاكاة بعد. سيُحدَّد نطاق المحرك ولغة التنفيذ بعد اختيار اللعبة الأولى ونظام Atari المستهدف؛ لا يعني وجود هذا المجلد أن المحاكاة أصبحت جاهزة.
