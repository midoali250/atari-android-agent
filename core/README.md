# Core module

وحدة Java مستقلة عن أندرويد، مرتبطة بالتطبيق عبر `implementation(project(":core"))`.

## الموجود حاليًا

- `CoreStatus`: يوضح صراحة أن محرك المحاكاة واللعبة غير منفذين.
- `RomInventory`: ترتيب أسماء ملفات ROM المرشحة للتغليف، دون التحقق من محتواها أو حقوق توزيعها.
- اختبارات JUnit للحالة وامتدادات الأسماء والأسماء المكررة والمسارات المستبعدة.

**هذه ليست نواة محاكاة Atari.** لا يوجد تنفيذ لمعالج أو رسوم أو صوت أو تحميل لعبة حتى الآن.

```bash
./gradlew :core:test
```

سيُحدَّد تصميم المحرك ولغة التنفيذ بعد اختيار اللعبة والنظام المستهدفين. إذا أُضيفت مكتبات native لاحقًا، فيجب تحديث ربط أندرويد واختبارات الأجهزة وإعدادات ABI.
