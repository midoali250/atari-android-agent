# ROMs

مجلد ملفات الألعاب المستخدمة في الاختبار والتشغيل.

- لا توجد ألعاب مضمّنة في المستودع حاليًا.
- استخدم ملفات متوافقة مع نظام Atari الذي سيُحدَّد لاحقًا.
- استخدم فقط ملفات تملك حقوق استخدامها، ولا تضف إلى Git إلا ملفات تملك تصريحًا بتوزيعها.
- سيُوثَّق مسار التحميل والامتدادات المدعومة عند تنفيذ المحرك.

الملف `.gitkeep` يحفظ هذا المجلد في Git بينما يكون خاليًا من ملفات الألعاب.
