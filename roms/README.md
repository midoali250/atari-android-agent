# ROMs

لا تُضمَّن ملفات ROM في APK افتراضيًا، ولا توجد ألعاب داخل المستودع حاليًا.

لتضمين ملفات تملك تصريحًا بتوزيعها، ضعها مباشرة في هذا المجلد بامتداد `.a26` أو `.bin` أو `.a78`، ثم من جذر المشروع:

```bash
./scripts/build-apk.sh debug --bundle-roms
# أو
./gradlew :android:exportDebugApk -PbundleRoms=true
```

على Windows:

```bat
scripts\build-apk.bat debug --bundle-roms
```

- تُنسخ الملفات إلى `assets/roms/` داخل APK.
- المجلدات الفرعية والملفات الأخرى مثل README لا تُضمَّن.
- يتوقف البناء إذا فُعّل الخيار دون وجود ملفات مرشحة.
- العودة إلى البناء بدون الخيار تمسح ملفات ROM من مجلد الأصول المولّد.
- التطبيق يعرض الأسماء فقط؛ **لا يوجد محرك يشغّل هذه الملفات بعد**.
- الامتداد وحده لا يضمن صحة ROM أو توافقه مع نظام Atari المستهدف.

استخدم ملفات تملك حقوق استخدامها، ولا تضف إلى Git أو APK للتوزيع إلا ملفات تملك تصريحًا بتوزيعها. الخيار لا يتحقق تلقائيًا من التراخيص. الملف `.gitkeep` يحفظ المجلد في Git عندما يكون خاليًا من الألعاب.
