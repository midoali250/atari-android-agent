# التحقق من منظومة البناء

تاريخ التحقق المحلي: **2026-10-31**.

## البيئة

- Linux، JDK Temurin 17.
- Gradle Wrapper 8.11.1؛ بصمة التوزيعة مثبتة، وبصمة Wrapper JAR طابقت القيمة المنشورة رسميًا.
- Android Gradle Plugin 8.9.2.
- Android SDK Platform 35 وBuild Tools 35.0.0.

## النتائج المحلية

| الفحص | النتيجة |
| --- | --- |
| بناء نظيف وتصدير debug APK | ناجح |
| اختبارات وحدة `core` | 5 اختبارات ناجحة |
| اختبارات Android لنسخة debug | اختباران ناجحان |
| اختبارات Android لنسخة release | اختباران ناجحان |
| `lintDebug` و`lintRelease` | ناجحان دون مشكلات في الفحص النهائي |
| توقيع debug باستخدام `apksigner` | صالح، بمخطط APK Signature Scheme v2 |
| محاذاة APK باستخدام `zipalign` | ناجحة |
| هوية التطبيق ونقطة التشغيل في البيان | مطابقتان للإعدادات |
| بناء release بمفتاح اختبار مؤقت | ناجح؛ التوقيع صالح والتطبيق غير debuggable |
| بناء release بدون توقيع | مرفوض كما هو متوقع؛ لم يُصدّر APK غير موقّع |
| تضمين ملف تغليف اصطناعي بامتداد BIN | ظهر تحت `assets/roms/` فقط |
| استبعاد ملفات التوثيق من أصول ROM | ناجح |
| البناء التالي بدون خيار التضمين | أزال ملف الاختبار من APK |
| رفض تضمين ROM عند عدم وجود ملفات مرشحة | ناجح |

## حدود التحقق

- ملف الاختبار الاصطناعي ليس لعبة، وأُزيل بعد الفحص. لم تُضف أي ROM حقيقية.
- مفتاح release المؤقت ونسخة release المستخدمة للاختبار حُذفا. ليست هناك مفاتيح توقيع داخل المستودع.
- لم يُجرَ تثبيت أو اختبار لعب على هاتف فعلي أو محاكي ضمن هذا التحقق. نجاح التوقيع والتغليف لا يثبت تشغيل لعبة؛ لا يوجد محرك محاكاة بعد.
- تشغيل GitHub Actions مستقل عن هذه النتائج؛ راجع حالة كل تشغيل وArtifacts الخاصة به في صفحة Actions.

أوامر البناء وإعادة الفحص موجودة في [دليل بناء APK](BUILD_APK.md).
