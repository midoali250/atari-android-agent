# Android app

مساحة تطبيق الأندرويد الخاصة بالمشروع.

## النطاق المخطط

- واجهة التطبيق وإدارة ملفات الألعاب المحلية.
- عرض إطارات اللعبة وتشغيل الصوت.
- التحكم باللمس، ودورة حياة التطبيق، وإعدادات المستخدم.
- الاتصال بمحرك المحاكاة الموجود في `../core/`.

## الحالة الحالية

المجلد مهيأ فقط؛ لم تُضف ملفات Gradle أو شيفرة التطبيق بعد. سيُحدَّد إعداد البناء بعد اختيار اللعبة الأولى ونهج المحاكاة.
