# Android app

وحدة تطبيق الأندرويد `:android`، مبنية بـ Java وAndroid SDK دون اعتماد على واجهة مكتبة خارجية في النسخة المبدئية.

## التشغيل الحالي

`MainActivity` يعرض إصدار التطبيق ومعرّفه وحالة المشروع وأسماء ملفات ROM المضمّنة إن وُجدت. **لا ينفذ أي ROM أو محاكاة.** الواجهة متاحة بالإنجليزية والعربية.

- `applicationId` للإصدار: `com.midoali.atari`.
- نسخة debug تحمل اللاحقة `.debug` ويمكن تثبيتها بجوار الإصدار النهائي.
- أقل API: 26؛ SDK المستهدف والمترجم: 35.
- لا يطلب التطبيق صلاحية الإنترنت أو قراءة التخزين العام.

## البناء من جذر المستودع

```bash
./gradlew :android:exportDebugApk
./gradlew :android:testDebugUnitTest :android:lintDebug
```

الناتج: `../artifacts/apk/atari-android-debug.apk`.

إصدار release يتطلب توقيعًا عبر متغيرات البيئة الموضحة في [دليل البناء](../docs/BUILD_APK.md):

```bash
./gradlew :android:exportReleaseApk
```

لا تستخدم نسخة release غير موقّعة باعتبارها قابلة للتثبيت؛ يتحقق إعداد البناء من وجود مفتاح قبل إخراجها.

## التطوير القادم

عند تنفيذ المحرك، اربط `:core` بالعرض والصوت والتحكم ودورة حياة التطبيق، وأضف اختبارات جهاز فعلية. راجع قواعد R8 وواجهات JNI ومعماريات ABI إذا أُضيفت مكتبات native.
